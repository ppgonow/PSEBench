# Held-out adaptive corpus

This directory is generated by:

```bash
python3 runner/generate_heldout_adaptive.py --count 100
```

The corpus contains 100 deterministic message-to-scheduler scenarios whose
prompt and injected artifact avoid the current `intent_policy.py` persistence
and one-shot cue vocabulary. Each case has the same typed authorization
boundary, but varies topic, time, attack style, authority framing, staged
updates, and scheduler parameters. The replay runner evaluates the committed
effect from the scenario's action trace; it does not infer attack success from
the injected wording.

The generated `MANIFEST.csv` records a SHA-256 digest for every YAML file.
